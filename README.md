# 카드뉴스 자동화 렌더러

실화면 클립(스크린 녹화·공식 데모·스크린샷) 위에 라벨·제목·본문을 얹어서,
인스타 캐러셀에 올릴 4:5 카드를 **슬라이드별 개별 mp4/png**로 뽑는 도구입니다.
카드 한 장 = 클립 하나 + 텍스트 몇 줄. 덱 JSON 하나로 카드 여러 장을 한 번에 렌더합니다.

@ai_anharu 채널에서 실제로 쓰는 렌더 파이프라인 그대로입니다.

## 설치 (한 번이면 끝)

Node.js·git 몰라도 됩니다. Claude Code를 켠 상태에서(터미널에 `claude` 입력 후) 두 줄만 칩니다:

```
/plugin marketplace add anharu-dev/haru-cardnews
/plugin install haru-cardnews@haru-cardnews
```

설치 범위를 물어보면 **"Install for you (user scope)"** 를 고르세요 — 그래야 컴퓨터
**어느 폴더**에서 Claude Code를 켜든 동작합니다(project/local scope는 지금 켜져 있는
그 프로젝트에만 묶입니다).

**이게 전부입니다.** `git clone`·`npm install`을 따로 안 하셔도 됩니다.
처음 카드뉴스를 만들 때 필요한 부품을 한 번 받느라 몇 분 걸리는데, 그것도 알아서 합니다
(두 번째부터는 안 기다립니다). 영상 길이를 재는 도구도 안에 들어 있어서 ffmpeg 같은 걸
따로 깔지 않으셔도 됩니다.

설치되면 채팅창에 이렇게 치시면 됩니다:

```
카드뉴스 만들어줘
```

> 개발자라 렌더러 코드를 직접 보거나 고치고 싶으시면 아래 "내 카드뉴스 만들기" 절부터
> 보시면 됩니다 — 그건 `git clone`으로 별도 받는 경로입니다.

## 쓰는 법

**대화로 만들기 (권장)** — 채팅창에 이렇게 치면 됩니다.

```
카드뉴스 만들어줘
```

또는 커맨드로 바로 불러도 됩니다(같은 동작입니다):

```
/cardnews
```

주제를 인터뷰하고 → 기획안을 표로 보여주고 → 승인받고 → 렌더까지 합니다.
"2번 카드 제목 바꿔줘" 같은 수정도 대화로 됩니다(해당 카드만 다시 렌더).

**소재를 폴더에 직접 넣지 않으셔도 됩니다.** 방금 찍은 화면 녹화는 도구가 다운로드·바탕화면
폴더에서 알아서 찾아 목록으로 보여줍니다. 없으면 파일을 채팅창에 끌어다 놓거나 경로만
붙여넣으시면 나머지는 도구가 합니다.

## 무료 스톡 사진 (Unsplash, 선택 — 안 하셔도 됩니다)

본인 사진이 없어도 카드는 만들어집니다(텍스트만으로도 됩니다). 스톡 사진까지 쓰고 싶으실 때만
아래를 한 번 해두시면 됩니다 — **안 해도 도구는 그냥 넘어갑니다. 여기서 멈추지 않습니다.**

채팅창에 "스톡 사진 쓰고 싶어요"라고만 말씀하시면 됩니다 — 도구가 https://unsplash.com/developers
를 직접 열어드리고, 그 페이지에서 뭘 눌러야 하는지까지 순서대로 알려드립니다. 요약하면:

1. **Register as a developer** 클릭 → 이메일로 가입(**카드 등록 없음, 시간당 1,000장 조회까지
   무료**)
2. **New Application** → 약관 동의 → 이름·설명 아무거나 한 줄씩 → **Create application**
3. 그 페이지에 뜨는 긴 문자열(Access Key)을 채팅에 붙여넣으시면 도구가 알아서 저장합니다.

직접 넣고 싶으시면 `~/.claude/haru-cardnews.env`(Windows는
`C:\Users\<사용자>\.claude\haru-cardnews.env`)에 `UNSPLASH_ACCESS_KEY=받은키` 한 줄을
넣으시면 됩니다.

> 키를 **플러그인 폴더 안에 두지 않는 이유**: 플러그인을 다시 설치하면 그 폴더는 통째로
> 덮어써져서 키가 사라집니다. `~/.claude/` 아래에 두면 재설치해도 남습니다.

사진을 쓰면 `card.label`에 Unsplash와 작가명이 자동으로 표기됩니다.

**직접 JSON 써서 만들기** — Claude Code 없이도 됩니다. 아래 "내 카드뉴스 만들기" 절 참고.

## 렌더러만 먼저 확인

```bash
npm install
```

## 써보기 (샘플로 먼저)

```bash
npm run render
```

**주의: 이 명령어는 `sample` 덱 하나만 렌더하는 테스트용 고정 명령입니다.**
주제·자료를 물어보지 않습니다 — 그런 기능이 없고, 항상 `sample.json`만 렌더하도록
`package.json`에 고정돼 있습니다. 이걸로 진짜 카드뉴스가 만들어지지 않습니다, 도구가
정상 설치됐는지 확인하는 스모크 테스트일 뿐입니다.

`public/mediadecks/sample.json` 덱을 렌더해서 `out/sample/01.mp4`, `02.png`가 나옵니다.
샘플 클립(`public/clips/sample/sample.mp4`)은 저작권 문제 없는 자체 생성 테스트 영상입니다.

**내 카드뉴스를 만들려면 아래 "내 카드뉴스 만들기" 섹션으로 가서
`node scripts/mediacards.mjs <내덱이름>`을 직접 실행해야 합니다.**

## 내 카드뉴스 만들기

1. 클립(mp4 16:9 권장, 또는 png/jpg)을 `public/clips/<내주제>/`에 넣습니다.
2. `public/mediadecks/<내덱>.json`을 작성합니다:

```json
{
  "brand": { "handle": "@내계정", "theme": "mono-light" },
  "cards": [
    {
      "clip": "clips/내주제/영상.mp4",
      "label": "출처 · 한 줄",
      "title": "제목 첫 줄\n제목 둘째 줄",
      "body": ["본문 한 문장 = 한 줄.", "두세 줄이 적당합니다."]
    },
    { "cta": true, "title": "마무리\n한 마디", "body": ["행동을 유도하는 한 줄."], "action": "팔로우" }
  ]
}
```

3. 렌더:

```bash
node scripts/mediacards.mjs 내덱
```

`out/내덱/01.mp4 02.mp4 …` — 인스타 캐러셀에 번호 순서대로 올리면 됩니다.

카드 한두 장만 다시 만들고 싶으면:
```bash
node scripts/mediacards.mjs 내덱 --only 3,5
```

## 덱 스키마

| 필드 | 설명 |
|---|---|
| `brand.handle` | 인스타 핸들. `wordmark`를 안 주면 이게 카드에 찍힙니다 |
| `brand.wordmark` | 카드 최상단 중앙과 마무리 버튼에 박히는 표기. 없으면 `handle`을, 그것도 없으면 `AI 안하루`를 씁니다 — **둘 다 비우면 남의 브랜드명이 본인 카드에 나갑니다** |
| `brand.accent` | 강조색 hex(예: `"#1a7f5a"`). 주면 `theme` 프리셋 색을 덮어씁니다 — **자기 브랜드 색 쓰는 자리** |
| `brand.theme` | 액센트 색 프리셋: `mono-light`(기본, 흑백) · `claude`(코랄) · `gpt`(코발트) · `neon`(레드, 속보용) · `gemini`(구글 블루) |
| `brand.surface` | `light`(기본, 하단이 흰 배경) · `dark`(카드 전체가 통짜 블랙). **주의**: `theme`만으로는 검정 카드가 안 나옵니다 — 검정 판형을 쓰려면 반드시 이 필드를 `dark`로 지정하세요 |
| `brand.texture` | `true`면 아주 옅은 종이질감(입자)을 깝니다. 기본 꺼짐. 자료 창 위에는 안 깔립니다. 켜면 파일이 꽤 커집니다(입자는 압축이 잘 안 됩니다) |
| `card.full` | `true`면 **전면 판형** — 자료가 카드를 꽉 채우고 하단 그라데이션 위에 흰 글자가 얹힙니다. 사진·생성이미지처럼 자료가 주인공일 때 씁니다. 화면 녹화(16:9)에는 쓰지 마세요, 4:5에 맞추느라 좌우가 크게 잘립니다 |
| `card.clip` | 영상(mp4) 또는 이미지(png/jpg). 영상은 원본 길이 그대로 쓰되 10~20초로 자릅니다(10초 미만은 렌더가 멈춥니다). 이미지는 기본이 **정지 PNG** — 켄번즈(합성 확대)를 걸고 싶으면 `card.motion: true`를 같이 주세요 |
| `card.motion` | `true`면 이미지 소스에 켄번즈를 걸어 mp4로 뽑습니다. 기본 꺼짐(정지 이미지). 화면 녹화(mp4)는 이 필드와 무관하게 항상 그 자체로 영상입니다 |
| `card.label` | 클립 아래 캡션 한 줄(출처 표기용) |
| `card.title` | `\n`으로 줄바꿈 직접 지정. `*단어*`로 감싸면 그 부분만 액센트 색으로 강조됩니다(아래 예시 참고) |
| `card.body` | 배열 = 한 문장 한 줄, 0~3줄. 여기도 `*구절*`로 굵기 강조 가능 |
| `card.duration` | 카드 길이(초) 직접 지정, 생략 시 자동. 지정해도 10~20초 범위 안으로 맞춰집니다 |
| `card.badge` | 카드 왼쪽 위 작은 라벨 칩(예: `"TREND"`). 짧은 한두 단어만 — 위치·색은 고정, 문구만 바뀝니다. cta 카드엔 안 붙습니다 |
| `card.cta` | `true`면 클립 없이 텍스트만 있는 마무리 카드(정지 PNG로 렌더) |
| `card.keyword` | cta 카드에서 "계정명 · 댓글에 '키워드'" 알약 버튼을 만듭니다 |
| `card.action` | cta 카드 알약 문구. `keyword`가 없을 때 사용(기본값 "팔로우") |
| `card.compare` | `{ left: {label, text}, right: {label, text} }` — 클립 없이 두 항목을 나란히 대비시키는 비교(vs) 카드. `card.body[0]`이 있으면 패널 아래 캡션 한 줄로 나갑니다 |
| `card.steps` | 문자열 배열 — 클립 없이 번호(01, 02…) 매긴 목록을 세로로 나열하는 단계 카드. 3~5개 권장 |

### 강조 문법 (`*텍스트*`)

`title`·`body` 문장 안에서 `*단어*`로 감싸면 그 부분만 강조됩니다:

```json
{ "title": "AI 영상 한 편 뽑는 값\n*4,800원*부터." }
```

→ 제목에서 "4,800원"만 액센트 색(테마에 따라 코발트·코랄·레드 등)으로 두껍게 찍힙니다.
본문(`body`)에서 쓰면 색 대신 굵기로만 강조됩니다.

## 규칙 (이건 코드가 아니라 지켜야 하는 것)

- **영상 카드는 10초 이상이어야 렌더됩니다.** 10초 미만 클립은 렌더가 멈추고 에러를 냅니다 — 패딩으로 늘리지 말고 소재를 바꾸세요(마지막 프레임이 얼어붙습니다).
- **인용 자료의 저작권은 여러분에게 없습니다.** 남의 영상·스크린샷을 쓸 땐 출처를 `label`에 밝히고, 발행 플랫폼의 인용·공정이용 범위를 넘지 않는지 직접 확인하세요. 이 도구는 렌더만 할 뿐 저작권을 대신 판단해주지 않습니다.
- 오디오 트랙은 렌더하지 않습니다(`--muted`). 인스타는 카드 안에 소리가 있으면 자동으로 "오리지널 오디오"로 잡아 음악을 못 붙입니다 — 소리는 인스타 앱 안에서 얹으세요.
